# Guia de instalacion - Geolocalizador-Encuentrame

## Instalacion en aeronaves

### Requisitos previos
- Autorizacion de la autoridad de aviacion civil (DGAC, FAA, EASA)
- STC para el tipo de aeronave
- Personal certificado en avionica

### Procedimiento

1. **Seleccion de ubicacion**
   - Estabilizador vertical, cono de cola o raiz de ala
   - Zona con estructura reforzada
   - Acceso para mantenimiento

2. **Fijacion mecanica**
   - Soportes de montaje segun STC
   - Pernos de anclaje con torque especificado
   - Sellado con compuesto anti-vibracion

3. **Conexion electrica**
   - Alimentacion desde bus de emergencia (28V DC)
   - Interfaz ARINC 429 para datos de vuelo
   - Cableado con proteccion EMI

4. **Pruebas funcionales**
   - Verificacion de comunicacion con bus
   - Simulacion de activacion manual
   - Prueba de transmision 406 MHz

### Documentacion requerida
- Formulario 337 (FAA) o equivalente
- Registro de instalacion en bitacora de aeronave
- Certificado de instalacion

## Instalacion en embarcaciones

### Requisitos previos
- Permiso de Capitanía de Puerto
- Inspeccion de casco para puntos de montaje

### Procedimiento

1. **Montaje**
   - Soporte con liberacion hidrostatica
   - Ubicacion en cubierta alta
   - Orientacion vertical

2. **Conexiones**
   - Alimentacion desde baterias de emergencia
   - Sensor de presion para deteccion de hundimiento

3. **Pruebas**
   - Activacion manual
   - Verificacion de flotacion
   - Prueba de transmision AIS

---

## Instalacion en infraestructura terrestre

### Requisitos previos
- Estudio de estructura de soporte
- Permiso de propietario de infraestructura

### Procedimiento

1. **Fijacion**
   - Soportes ajustables a poste, torre o caseta
   - Anclajes quimicos o mecanicos
   - Altura minima 3 m

2. **Alimentacion**
   - Panel solar + bateria de respaldo
   - Conexion a alimentacion redundante si existe

3. **Comunicacion**
   - Antena externa para LoRaWAN o Iridium
   - Orientacion para maxima cobertura satelital

---

## Instalacion personal

- Clip o correa de transporte
- Activacion manual mediante boton
- Sin instalacion fija
