# Hardware - Geolocalizador-Encuéntrame

Esta carpeta contiene los esquemas y diseños del dispositivo.

## Versiones principales

### Encuéntrame-Aero (aviación)
- Cápsula de eyección para impacto inminente (300–1000 m AGL).
- Material compuesto de alta resistencia.
- Peso: 980 g.
- Protección IP69K.

### Encuéntrame-Mar (marítimo)
- Cápsula con liberación hidrostática.
- Flotadores hinchables.
- Peso: 1200 g.
- Resistencia a presión y corrosión.

## Versiones secundarias (observación)

### Encuéntrame-Terrestre
- Diseño adaptable a postes, torres, casetas.
- Activación por robo o pérdida de señal.
- Peso: 500 g.

### Encuéntrame-Personal
- Clip o correa de transporte.
- Activación manual.
- Peso: 200 g.
